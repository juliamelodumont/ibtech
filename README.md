## 👩‍💻 Sobre o projeto

Cartão de visitas digital pessoal criado com **HTML, CSS e JavaScript puros** — sem frameworks, sem bibliotecas externas.

Uma página para apresentar quem sou, minha trajetória e onde me encontrar.

---

## ✨ Funcionalidades

| # | Interação | Descrição |
|---|-----------|-----------|
| 1 | 🌙 Dark Mode | Alterna entre tema claro e escuro, salva no `localStorage` |
| 2 | 📧 Copiar e-mail | Clique no e-mail para copiar, notificação animada de confirmação |
| 3 | 🔍 Scroll Spy | Link do menu fica destacado conforme a seção visível na tela |
| 4 | ⌨️ Animação de digitação | Frases animadas no cargo/título da hero section |

## 📱 Responsividade

| Breakpoint | Comportamento |
|------------|---------------|
| Desktop (> 768px) | Layout em duas colunas, nav completa |
| Tablet (≤ 768px) | Layout em coluna única, nav simplificada |
| Mobile (≤ 480px) | Ajustes de tipografia e espaçamento |

---

## 🎨 Personalização

As cores podem ser alteradas facilmente editando as variáveis no topo do `style.css`:

```css
:root {
    --cor-primaria:   #7c3aed;   /* viola — cor principal */
    --cor-secundaria: #ec4899;   /* rosa  — gradientes */
}
```
